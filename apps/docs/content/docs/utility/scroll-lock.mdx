---
title: Scroll Lock
description: Lock page scroll while keeping scroll inside a specific element (modals, drawers, overlays).
---

The `ScrollLock` component locks page scrolling while it is mounted, but still lets the user scroll inside the element it renders (and any `shards` you pass). It removes the page scrollbar without layout shift by compensating for the scrollbar's width.

It is a component wrapper around the `useScrollLock` hook from `@zayne-labs/toolkit-react`, and follows the same API as `RemoveScroll` from [react-remove-scroll](https://github.com/theKashey/react-remove-scroll).

## Installation

```package-install
@zayne-labs/ui-react
```

## Basic Usage

`ScrollLock` renders a `div` by default. Scrolling is allowed inside that element and blocked everywhere else.

```tsx
import { ScrollLock } from "@zayne-labs/ui-react/common/scroll-lock";

function Modal({ children }) {
	return (
		<div className="fixed inset-0 bg-black/50">
			<ScrollLock className="max-h-[80dvh] overflow-y-auto">{children}</ScrollLock>
		</div>
	);
}
```

## Toggle with `enabled`

Instead of unmounting, you can turn the lock on and off with `enabled`.

```tsx
<ScrollLock enabled={isOpen} className="overflow-y-auto">
	<DrawerContent />
</ScrollLock>
```

## Shards

Shards are extra elements that stay scrollable and interactive while the lock is active. Use them for things rendered outside the lock, like a toast region or a teleported popover.

```tsx
function App() {
	const toastRegionRef = useRef<HTMLDivElement>(null);

	return (
		<ScrollLock shards={[toastRegionRef]}>
			<DialogContent />
		</ScrollLock>
	);
}
```

## Options

| Prop              | Default    | Description                                                                            |
| ----------------- | ---------- | -------------------------------------------------------------------------------------- |
| `enabled`         | `true`     | Whether the lock is active.                                                            |
| `removeScrollBar` | `true`     | Hide the page scrollbar (and compensate for its width).                                |
| `gapMode`         | `"margin"` | Compensate for the removed scrollbar with `margin-right` or `padding-right` on `body`. |
| `inert`           | `false`    | Block pointer interactions outside the lock and shards, not just scrolling.            |
| `noIsolation`     | `false`    | Only lock the page scroll; don't block scroll events outside the lock.                 |
| `allowPinchZoom`  | `false`    | Allow pinch-zoom (and `ctrl` + wheel zoom) while locked.                               |
| `noRelative`      | `false`    | Don't set `position: relative` on `body` while locked.                                 |
| `shards`          | —          | Extra elements (refs, elements or getters) that stay scrollable while locked.          |
